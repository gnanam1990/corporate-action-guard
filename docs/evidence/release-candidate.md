## How to close the gap

```bash
pnpm testnet:status                       # names the missing precondition
# fund the deployer at https://www.okx.com/xlayer/faucet  (~0.00012 OKB)
pnpm testnet:deploy && pnpm testnet:prove # regenerates this file with tx hashes
```

Each scenario submits a real transaction or simulated call and records its hash and block. A
scenario that reverts for the **wrong** reason is recorded as a FAILURE, not a pass.

## Standing limitation

Even once every scenario passes, this proves the guard rejects stale, mutated, replayed,
expired, and unsafe-window operations **against a labelled TESTNET FIXTURE**. It does not
prove compatibility with production xStocks scheduling semantics, which are not published in
a form this build could verify.
